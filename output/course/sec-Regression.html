    Section Scatter Plots and Regression Lines

    When two data items are collected for every person or object in a sample, the data items can be visually displayed using a scatter plot.
    🔗

    Definition 4.90. Scatter Plot.

    A scatter plot is a type of plot that displays the relationship between two numerical variables. Each point on the plot represents a single observation, with its position determined by the values of the two variables.
    🔗
    🔗

    Example 4.91.

    Consider the relationship between the number of hours studied and the test scores of students. A scatter plot would display each student as a point, with the x-axis representing hours studied and the y-axis representing test scores.
    🔗
    Solution.
    By plotting the data points on a scatter plot, we can visually inspect the relationship between the two variables. The resulting chart displays a clear upward trend from left to right, showing a positive linear association.
    🔗
    🔗
    🔗

    Checkpoint 4.94.

    Make a scatter plot for the given data provided in Table 4.95. Use the scatter plot to describe whether or not the variables appear to be related.
    🔗
    Solution.
    By examining the scatter plot in Figure 4.96, we can visually interpret the relationship between the two variables.
    🔗
    As we look from left to right along the horizontal axis, the data points show a clear upward pattern. This tells us that as variable \(x\) increases, variable \(y\) generally increases as well. Because the points follow a relatively straight, rising path, the variables appear to have a strong, positive linear correlation.
    🔗
    🔗
    🔗

    Note 4.97.

    A scatter plot can be used to determine whether two quantities are related. If there is a clear relationship, the quantities are said to be correlated. Correlations can often be seen when data items are displayed on a scatter plot. Although the scatter plot in Example 4.91 indicates a correlation between education and prejudice, we cannot conclude that increased education causes a person’s level of prejudice to decrease.
    🔗
    🔗
    Regression in statistics is a modeling technique used to estimate the relationship between a dependent variable (the outcome) and one or more independent variables (the predictors).
    🔗
    It allows you to understand how changes in the predictors are associated with the outcome, which is highly useful for forecasting, making predictions, and identifying trends.
    🔗

    A statistics professor wants to examine the relationship between a student’s shoe size (\(X\)) and their score on the final exam (\(Y\text{,}\) measured as a percentage). The data collected from a random sample of five students is presented below.
    🔗
    Using the simple linear regression model calculated from the observed data table above, predict the expected final exam score of a student who wears a shoe size of \(10\) (i.e., \(X = 10\)).
    🔗
    • 65%
    • Incorrect. While some individual students score near this range, this value deviates from the baseline sample average predicted by a zero-correlation model.
    • 79%
    • Correct! Because there is no linear relationship between shoe size and exam scores, the slope is approximately 0, meaning the best prediction for any shoe size is simply the mean of the observed scores (\(\bar{Y} = 79\)).
    • 95%
    • Incorrect. This prediction assumes a positive correlation where larger shoe sizes guarantee higher test scores, which is not supported by the data pattern.
    • 50%
    • Incorrect. This assumes an artificial downward trend that does not match the random distribution of the data sample.
    Solution.
    To predict the exam score for a student with a shoe size of 10, we graph the data points from the table and calculate the line of best fit using linear regression.
    🔗

    🔗
    Depending on the nature of your data and the relationship you are trying to analyze, there are several standard regression models:
    🔗

    Simple Linear Regression.

    Simple linear regression is a statistical method that models the relationship between a single independent variable and a continuous dependent variable by fitting a linear equation to observed data. It plots a straight line of best fit. The equation of the line is typically expressed as a linear function of the form \(y = mx + b\text{,}\) where \(m\) represents the slope of the line and \(b\) represents the y-intercept.
    🔗
    🔗

    Example 4.107.

    Think of ice cream sales based on the outside temperature:
    • Temperature (\(x\)): The independent variable.
      🔗
      🔗
    • Ice Cream Sales (\(y\)): The dependent variable.
      🔗
      🔗
    🔗
    As temperature (\(x\)) goes up, ice cream sales (\(y\)) go up. A simple linear regression draws a straight line through your past data to help you predict exactly how many ice creams you will sell on a hot 90°F day versus a cool 60°F day.
    🔗
    Solution.
    By establishing the linear equation from historical data, the business can accurately input the predicted weather temperature (\(x\)) to yield an expected inventory target (\(y\)).
    🔗
    🔗
    🔗

    Checkpoint 4.108.

    The relationship between the number of widgets in a package and the length of the package, in inches, is given in the table below.
    🔗
    1. What is the slope of the line of best fit (linear regression)? (Widgets on \(x\)-axis, Length on \(y\)-axis)
      🔗
      🔗
    2. What is the value of the y-intercept of the linear regression?
      🔗
      🔗
    🔗
    Solution.
    Part a) Slope Calculation: The formula for the slope (\(m\)) of a line passing through coordinates \((x_1, y_1)\) and \((x_2, y_2)\) is:
    \begin{equation*} m = \frac{\Delta y}{\Delta x} = \frac{y_2 - y_1}{x_2 - x_1} \end{equation*}
    🔗
    Using sequential points from the data table like \((3, 9.00)\) and \((4, 9.25)\text{:}\)
    \begin{equation*} m = \frac{9.25 - 9.00}{4 - 3} = \frac{0.25}{1} = 0.25 \end{equation*}
    Because the data is perfectly linear, the slope of the line of best fit is exactly 0.25.
    🔗
    Part b) Y-Intercept Calculation: The slope-intercept form of a linear equation is given by:
    \begin{equation*} y = mx + b \end{equation*}
    🔗
    Substituting our known slope \(m = 0.25\) and the first data coordinate point \((3, 9.00)\) allows us to solve for \(b\text{:}\)
    \begin{align*} 9.00 \amp = 0.25(3) + b\\ 9.00 \amp = 0.75 + b\\ b \amp = 9.00 - 0.75 = 8.25 \end{align*}
    Thus, the value of the y-intercept is 8.25, which corresponds to a complete formula of \(y = 0.25x + 8.25\text{.}\)
    🔗
    🔗
    🔗
    Standard least-squares linear regression is a statistical method used to find the best-fitting straight line through a set of data points. It is the most common technique for modeling the relationship between a dependent variable (\(y\)) and one or more independent variables (\(x\)).
    🔗
    The least-squares method is a mathematical approach that minimizes the sum of the squares of the residuals (the differences between observed and predicted values). This method ensures that the line of best fit is as close as possible to all data points, providing the most accurate representation of the relationship between the variables.
    🔗

    Standard Least-Squares Linear Regression.

    The Linear Equation The definition models the data using the equation of a straight line:
    \begin{equation*} y = mx + b \end{equation*}
    where \(m\) is the slope and \(b\) is the y-intercept.
    🔗
    Formulas for Coefficients The parameters \(m\) and \(b\) are calculated directly using the following least-squares formulas:
    \begin{equation*} m = \frac{n\sum(xy) - \sum x \sum y}{n\sum(x^2) - (\sum x)^2} \end{equation*}
    \begin{equation*} b = \frac{\sum y - m\sum x}{n} \end{equation*}
    • \(\sum x\) is the sum of all \(x\)-variables.
      🔗
      🔗
    • \(\sum y\) is the sum of all \(y\)-variables.
      🔗
      🔗
    • \(\sum(xy)\) is the sum of the product of each paired \(x\) and \(y\) value.
      🔗
      🔗
    • \(\sum(x^2)\) is the sum of the squares of all \(x\)-variables.
      🔗
      🔗
    • \(n\) is the total number of data points.
      🔗
      🔗
    🔗
    🔗
    This method provides a powerful tool for understanding and predicting relationships in data, making it a fundamental technique in statistics and data analysis.
    🔗

    Example 4.111.

    The table below shows the relationship between total fat grams and the total calories in a selection of fast food sandwiches. Find the linear regression equation that models this data. Round all values to the nearest integer.
    🔗
    Solution.
    To find the line of best fit \(y = mx + b\text{,}\) we apply the standard least-squares linear regression formulas for the slope (\(m\)) and the y-intercept (\(b\)):
    \begin{equation*} m = \frac{n\sum(xy) - \sum x \sum y}{n\sum(x^2) - (\sum x)^2} \end{equation*}
    \begin{equation*} b = \frac{\sum y - m\sum x}{n} \end{equation*}
    🔗
    Using the \(n = 7\) data points from the table, we sum the component variables:
    • \(\displaystyle \sum x = 170\)
      🔗
      🔗
    • \(\displaystyle \sum y = 3260\)
      🔗
      🔗
    • \(\displaystyle \sum (x^2) = 4752\)
      🔗
      🔗
    • \(\displaystyle \sum (xy) = 87830\)
      🔗
      🔗
    🔗
    Substituting these values into our slope equation yields:
    \begin{equation*} m = \frac{7(87830) - (170)(3260)}{7(4752) - (170)^2} = \frac{614810 - 554200}{33264 - 28900} = \frac{60610}{4364} \approx 13.305 \end{equation*}
    Rounding to the nearest integer gives a slope of 13.
    🔗
    Next, we calculate the precise y-intercept using the unrounded slope value:
    \begin{equation*} b = \frac{3260 - (13.30492)(170)}{7} \approx 142.595 \end{equation*}
    Rounding to the nearest integer gives a y-intercept of 143.
    🔗
    Therefore, the final linear regression model is:
    \begin{equation*} y = 13x + 143 \end{equation*}
    🔗
    🔗
    🔗

    Example 4.114.

    During a solar eclipse, the temperature begins to drop as the Moon comes between the Earth and the Sun. The cooling temperatures, up through totality, of the eclipse are shown in the table below. Using a linear regression equation, predict the temperature at the 4 minute mark during the cooling, to the nearest degree.
    🔗
    Select the predicted temperature at the 4 minute mark.
    🔗
    Solution.
    Step 1: Calculate the Regression Equation Using the standard least-squares formulas with \(n = 4\) data coordinates, we find the required summary metrics:
    • \(\displaystyle \sum x = 6\)
      🔗
      🔗
    • \(\displaystyle \sum y = 274\)
      🔗
      🔗
    • \(\displaystyle \sum(x^2) = 14\)
      🔗
      🔗
    • \(\displaystyle \sum(xy) = 389\)
      🔗
      🔗
    🔗
    Substitute these totals into the slope (\(m\)) and y-intercept (\(b\)) formulas:
    \begin{equation*} m = \frac{4(389) - (6)(274)}{4(14) - (6)^2} = \frac{1556 - 1644}{56 - 36} = \frac{-88}{20} = -4.4 \end{equation*}
    \begin{equation*} b = \frac{274 - (-4.4)(6)}{4} = \frac{274 + 26.4}{4} = \frac{300.4}{4} = 75.1 \end{equation*}
    This yields the linear modeling equation: \(y = -4.4x + 75.1\text{.}\)
    🔗
    Step 2: Evaluate at 4 Minutes Substitute \(x = 4\) directly into our regression model to find the expected cooling value:
    \begin{align*} y \amp = -4.4(4) + 75.1\\ y \amp = -17.6 + 75.1 = 57.5 \end{align*}
    Rounding \(57.5^\circ\text{F}\) to the nearest whole integer gives our target choice of 58\(^\circ\).

    Checkpoint 4.117.

    A morning radio talk show is running a “Winter Coat Campaign” to collect and deliver coats to local shelters. They are storing the coats until they reach their goal of 2100 coats. The table below shows the number of coats in storage at the end of each day of the campaign.
    🔗
    Find the linear regression equation rounded to the nearest hundredths, and predict the day the campaign will meet its goal.
    🔗
    Solution.
    Part a) Linear Regression Equation: By applying the least-squares formulas for a data pool where \(n = 6\text{,}\) we get the summary metrics: \(\sum x = 21\text{,}\) \(\sum y = 6500\text{,}\) \(\sum(x^2) = 91\text{,}\) and \(\sum(xy) = 24810\text{.}\)
    🔗
    Evaluating our slope and intercept formulas returns:
    \begin{equation*} m = \frac{6(24810) - (21)(6500)}{6(91) - (21)^2} = \frac{148860 - 136500}{546 - 441} = \frac{12360}{105} \approx 98.86 \end{equation*}
    \begin{equation*} b = \frac{6500 - (117.714)(21)}{6} \approx 737.33 \end{equation*}
    Thus, the linear modeling line of best fit is
    \begin{equation*} y = 98.86x + 737.33 \end{equation*}
    🔗
    Part b) Goal Prediction: To compute the target milestone, substitute \(y = 2100\) into the verified equation:
    \begin{align*} 2100 \amp = 98.86x + 737.33\\ 1362.67 \amp = 98.86x\\ x \amp \approx 13.78 \end{align*}
    Because the data tracks totals at the end of each day, reaching \(13.78\) means the campaign will successfully complete its goal on Day 14.
